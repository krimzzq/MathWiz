# MathWiz University

Тренажёр по высшей и дискретной математике с теорией, практикой, контрольными, справочником формул и работой над ошибками.

## Запуск

Для GitHub Pages выберите **Settings → Pages → Deploy from a branch**, затем **main** и **/ (root)**. В корне ветки должны лежать `index.html`, `.nojekyll` и папка `assets`. Сборка и установка зависимостей не требуются.

Для локальной проверки запустите статический HTTP-сервер в этой папке, например `python -m http.server 8000`, и откройте `http://localhost:8000/`.

## Данные и контрольные

Гостевой профиль, избранное, прогресс и черновики хранятся в браузере. Данные старого облачного сайта привязаны к его адресу. Новая версия начинает с чистого профиля. В настройках можно удалить историю. В статической версии отсутствуют облачная панель администратора и сбор аналитики.

Задания генерируются на устройстве. Контрольные рассчитаны на самостоятельную тренировку.

## Файлы

- `assets/app.js` содержит интерфейс и учебные материалы перенесённой версии.
- `assets/learn.js` управляет гостевым профилем, прогрессом и контрольными.
- `assets/tasks.js` генерирует задания и проверяет ответы.
- `assets/licenses/` содержит лицензии сторонних библиотек.
